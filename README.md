# 轻采 · 亚马逊评论采集

一个围绕 ASIN 输入框设计的 Windows 桌面应用。输入商品 ASIN，选择站点和采集模式，即可将评论与商品信息保存为 Excel。

**[下载最新版 Windows 安装包](https://github.com/Hymingture/qingcai-releases/releases/latest)**

## 安装与使用

1. 在下载页的 Assets 中选择 `Qingcai-Setup-版本号-x64.exe`，下载并安装。
2. 打开轻采，点击右上角设置图标，填写自己的 Sorftime Account-SK。
3. 输入 ASIN，选择站点和模式，点击“开始收集”。默认美国站、最近 500 条。
4. 任务完成后点击“下载”，选择 Excel 保存位置。

支持 Windows 10/11 64 位；不需要安装 Python、Node.js 或 Codex。联网采集需要可用的 Sorftime 账户及额度。

## 主要功能

- 支持 13 个亚马逊站点，以及最近 500 条、全部评论、各星级 100 条三种模式。
- 首页显示最近 10 个任务；可查看全部历史、搜索商品和再次下载。
- 任务显示商品主图、ASIN、商品标题、模式、日期及当前状态。
- Excel 包含“商品信息”和“评论明细”两张工作表，保留原始评论字段，并包含可获取的主图、商品标题、品牌、价格、销量等信息。
- 密钥由 Windows 加密保存在当前电脑；任务和结果保存在本机。

接口可能只返回部分可获取的评论，“全部评论”指 Sorftime 当前可返回的全部记录。各星级模式属于分层样本，不能代表自然星级比例。缺失数据会明确标注。

## 应用内更新

从 1.2.0 起，启动后自动检查新版本；也可在“设置 → 软件更新”中手动检查。

发现新版后，选择“下载更新”，完成后点击“重启并更新”。下载和安装由你决定，关闭应用不会自动安装。采集或表格保存进行中，请先完成或取消任务。更新前会备份本机设置与任务记录。

1.1.1 及更早版本需手动安装 1.2.0 或更高版本一次，以启用应用内更新。下载更新无需 GitHub 账户或 Token。
